# Joshua Kirby - Portfolio

Personal portfolio showcasing AI/ML projects. Built with Next.js and deployed on Cloudflare.

## Tech Stack

- Next.js + React + TypeScript
- Tailwind CSS + shadcn/ui
- OpenNext for Cloudflare deployment

## Features

- **100% SSG** - All pages pre-rendered at build time
- **Markdown case studies** - Custom React components embedded in markdown
